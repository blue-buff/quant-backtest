# 预测力实验日志（EXPERIMENTS）

> 目标：把模型样本外预测力从"投骰子"（RankIC ≈ 0.01）提升到"勉强可用"（RankIC ≥ 0.02、RankICIR ≥ 0.2、跨池跨行情稳定为正）。
> 铁律：**只看样本外测试段**（2025-01-01 ~ 2026-08-14；滚动实验含 2024Q4）；所有指标从 mlruns 与 pred.pkl 原始产物读取，可被第三方复查。
> 每次尝试：yaml 变更 → git 提交 → run_exps 留痕（results/exps/<name>/）+ eval_pred 评估 JSON（results/eval/<name>.json）。

## 基线（要超越的对象）
- 数据 2023-01 起、RobustZScoreNorm、标签 1 日、单模型单种子、一次性训练（提交 e4df9c8 时代）
- hs300 测试段：IC **-0.0065** / ICIR -0.041 / **RankIC +0.0136** / RankICIR +0.085
- 判定标准（调研报告）：IC<0.01 = 噪声；0.01~0.02 = 边缘；0.02~0.05 = 可用；ICIR>0.5 稳定

### 滚动 walk-forward（10d，v2 数据，5 窗口）
- hs300：2024Q4 +0.091 / 2025Q2 +0.051 / 2025Q4 -0.010 / 2026Q2 +0.022 / 2026Q3 +0.101；拼接后 RankIC 0.0450（非重叠 0.0334，p=0.097）
- zz500：2024Q4 -0.034 / 2025Q2 +0.077 / 2025Q4 -0.001 / 2026Q2 +0.013 / 2026Q3 +0.084；拼接后 RankIC 0.0207（非重叠 0.0014，p=0.468）
- 结论：滚动重训对 hs300 帮助大（一次性 0.0196 → 滚动 0.0450），zz500 窗口间波动大
